# CampusNotes

CampusNotes is a simple, responsive VCS study-notes manager built with HTML, CSS and JavaScript.

## Features
- Create, edit and delete notes
- Organize notes by VCS topic
- Search notes by title, content or category
- Sort notes by date or title
- Save notes in browser Local Storage
- Responsive layout for desktop and mobile

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Run the project
1. Download or clone this repository.
2. Open the `CampusNotes` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Create and organize your VCS notes.

## Note
Notes are saved in the browser's Local Storage on the device and browser where they were created. They are not automatically synced between devices.
